# Contributing to Miragon projects

Thanks for your interest in our projects!

## Issues are welcome

Found a bug, have an idea, or want to ask a question? Please open an issue in the repository it relates to. Issues are the best way to reach us, and we read all of them.

## Pull requests

Most of our repositories accept pull requests from collaborators only, so you may not be able to open one. This helps us keep maintenance manageable and is not a judgment of your work.

Instead of a pull request, please open an issue describing the problem or your idea. If a repository accepts external pull requests, or has its own `CONTRIBUTING.md`, the rules stated there apply.

## Security

Please do not report security vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) where it is enabled, or contact us directly.
